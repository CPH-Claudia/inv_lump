# 躉繳投資型客戶推薦名單專案

## 1. 專案背景

本專案目標是從既有客戶中，找出未來較有可能購買躉繳投資型商品的客戶，形成推薦名單，提供業務分批拜訪與後續追蹤。

過去曾針對期繳投資型商品建立推薦名單，透過 Look-alike Modeling 找出與既有成功客戶相似的潛在客戶。期繳名單追蹤結果顯示，推薦名單具備實際轉換能力，且拜訪後成交率明顯高於整體名單成交率。

因此，本次躉繳投資型專案進一步將推薦邏輯升級為「規則分數 + 機器學習模型分數 + 分批釋出機制」，希望不只找出高潛力客戶，也能讓名單更符合業務實際拜訪節奏。

---

## 2. 專案目標

- 找出尚未購買躉繳投資型商品、但未來較可能購買的既有客戶
- 建立可解釋的 Rule Score
- 建立預測未來一年購買機率的 Model Score
- 整合最終 Final Score 進行客戶排序
- 依照業務可執行量進行分批釋出
- 追蹤拜訪率、成交率與後續名單效益

---

## 3. 資料來源

本專案主要使用以下資料：

- 保單資料
- 客戶基本資料
- 客戶收入資料
- 業務對應資料
- 拜訪紀錄資料
- 成交追蹤資料

## 4. 分析母體定義

### 正樣本

曾經購買過躉繳投資型商品的客戶。

為避免資料洩漏，模型不直接使用購買後資料，而是擷取其第一次購買躉繳投資型商品之前的客戶狀態，作為模型學習樣本。

### 候選客戶

截至分析時間點，尚未購買過躉繳投資型商品的既有客戶。

這些客戶會進入評分流程，最終依分數排序後形成推薦名單。

---

## 5. 方法設計

### 5.1 Rule Score

Rule Score 用來衡量客戶行為輪廓是否接近歷史躉繳投資型客群。

主要觀察面向包含：

- 保單數
- 壽險保單數
- 近一年保單數
- 累計保單總保費
- 壽險保費占比
- 壽險 FYC 占比
- 投保年資
- 距離最近投保天數
- 商品結構
- 客戶年齡與性別

Rule Score 的目的不是取代模型，而是提供一個較容易解釋的業務判斷基礎。

---

### 5.2 Model Score

Model Score 用來預測客戶未來一年內購買躉繳投資型商品的機率。

本專案採用 Snapshot 概念：

- 站在某一個觀察時間點
- 只使用該時間點以前的資料
- 預測未來 365 天是否購買躉繳投資型商品

這樣可以避免使用未來資訊，讓模型更接近實際上線情境。

---

### 5.3 雙模型路徑

由於部分客戶有收入資料，部分客戶沒有，因此本專案區分兩條模型路徑：

| 客戶類型 | 使用模型 |
|---|---|
| 無收入資料客戶 | 主模型 |
| 有收入資料客戶 | 收入模型 |

這樣可以避免收入資料缺漏造成模型偏誤，也能讓資料較完整的客戶使用更精準的評估方式。

---
